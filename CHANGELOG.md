# Changelog

## [1.3.0] — 2026-04-12

### Добавлено
- Кнопка выбора файла с диска (иконка скрепки, зелёная) в заголовке каждого пула

### Изменено
- Клик по области пула (заголовок или зона миниатюр) теперь **переключает режим захвата Ctrl+V** — повторный клик снимает режим захвата
- Выход из режима захвата при клике вне панелей скрипта
- Кнопка скрытия/показа панелей переработана: иконки-шевроны, размер 32×64 px
- Все кнопки-иконки в заголовке пула приведены к единому размеру 32×32 px

### Удалено
- Клик по области пула больше не открывает диалог выбора файла (эта функция перенесена на отдельную кнопку)
